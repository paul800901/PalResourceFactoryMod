## 已確認根因

2026-09-15 16:35 的本機 UE4SS 日誌：

```text
[PRFAncient] START_REFUSED Unsupported executable: native preview disabled
[PRFProcessor] DISABLED Unsupported executable: native preview disabled
```

同一輪 PalSchema 仍加入 `PRF_ResourceBreedingFacility` 與 `PRF_EggResourceProcessor`。
兩個 native target 都在初始化最前面建立 `SettlementEntries`，其 `resolve_native()` 原先只接受 1.0.4 的 PE timestamp。
這次在任何自訂模型、輸入限制、面板處理和自動結算 hook 註冊前停止。
因此能共同解釋資源繁殖場回到原版外觀、V 設蛋選項重新出現、自動支解停止。
這不是證明遊戲存檔損壞，也不能推論三個功能在新版已恢復。

## 操作

1. 啟動遊戲，進入拋棄式世界。
2. 使用一座原版的單顆「帕魯蛋孵化器」，不使用大型／電能批量孵化器或本專案舊建築。普通單顆孵化器不需要電力。
3. 放一顆帕魯蛋，等到孵化時間完成，但不要按住按鍵領取。世界內只留這一座已完成的單顆孵化器，避免選錯蛋。
4. 在遊戲中按一次 Ctrl + Alt + F8。
5. 等約五秒後退出遊戲，保留 UE4SS.log。畫面不會發材料、不會移除蛋，也不會跳成功視窗；是否成功以日誌為準。

本次不需要重新建造 26／36 級建築，也不用準備蛋糕或發電機。

## 判讀

日誌位置：
`E:\Program Files (x86)\Steam\steamapps\common\Palworld\Mods\NativeMods\UE4SS\UE4SS.log`

- `[PRFProbe] READY`：測試模組已載入，等待手動按鍵。
- `[PRFProbe] REFUSED ...`：前置資料不符合。不得視為掉落結算成功；訊息會說明缺少已完成的蛋、尚無後代資料、版本／資料布局不符等原因。
- `stage=construct-transient`：開始建立暫時的個體參數 UObject，不是場景角色，也不加入帕魯終端。
- `stage=native-call`：開始呼叫本機原版支解機率函式。
- `stage=native-return`、`drop item=... count=...`：原版回傳的材料清單。
- `PREVIEW_OK`：本次同步呼叫與列印已完成，未刪蛋、未發材料。仍需確認退出及再次登入正常；不等於正式模組完成。

只准每次遊戲啟動成功進入原版計算一次。前置檢查未過可重新操作。
這會使用遊戲原版亂數，不是完全唯讀；清單不儲存為待領獎勵，也不供正式版本重抽套用。
若日誌停在 native-call 或遊戲崩潰，保留日誌與崩潰報告，不再連續重試。

## 安裝與停用

- 本機編譯：`native\build_native.ps1 -Target PalResourceFactoryProbe`
- 遊戲關閉後首次安裝：`tools\install_probe.ps1`
- 只新增 UE4SS Mods 下的 `PalResourceFactoryProbe`，不修改其他模組、建築資料或存檔。
- 安裝前核對被研究 EXE 的完整 SHA256；執行時再檢查 PE 版本、原版入口位元組、相關反射欄位位置與大小。
- 停用：關閉遊戲，把此模組目錄的 `enabled.txt` 改名為 `enabled.disabled`。不需要移除其他模組或建築 ID。

沒有按鍵請求時，每幀只檢查一個原子旗標；不掃描物件、不處理蛋、不呼叫掉落公式。
舊的 PalResourceFactoryNative 及 0.3.5 建築包維持隔離；本次沒有啟用它們。
